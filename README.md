# XIT EDVAN — projeto Flutter

Este é um projeto-fonte multiplataforma para Android e iOS, com um painel auxiliar
de sensibilidade e visual preto/azul. Ele não modifica nem interage com o Free Fire.

## Como compilar
1. Instale o Flutter SDK e configure Android Studio para Android.
2. Extraia este ZIP e abra a pasta `xit_edvan_flutter`.
3. Execute `flutter pub get`.
4. Android: execute `flutter build apk --release`.
5. iOS: em um Mac com Xcode instalado, execute `flutter build ios --release`.
   Para instalar/publicar no iPhone, é necessário configurar assinatura Apple
   (certificado e provisioning profile) e cumprir as regras da App Store.

## Observações
- Este ZIP contém o código-fonte, não um APK ou IPA já compilado.
- Não há hack, aimbot, automação de tiros, alteração de arquivos do jogo ou
  promessa de evitar banimento.
